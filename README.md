# 行业选股研究系统

一个面向二级市场基本面研究的 Codex Skill，用于把用户已经确认的行业方向，转化为可复现、可维护的 A 股研究与选股项目。

> 受《投资中不简单的事》启发：先由投资者判断未来几年利润最可能产生在哪个行业，再让 Agent 把行业判断落实为公司筛选、盈利预测、估值与持续跟踪。

## 使用前提

这个 Skill **不负责替用户决定研究哪个行业**。使用前，用户应当先提出并确认一个值得研究的行业方向，例如 AI 产业链、创新药、机器人、储能或其他具有中期利润增长可能性的行业。

行业确认后，Agent 将继续回答：

- 行业增长来自哪里，未来利润池落在哪些环节；
- 需求增长会不会被扩产、竞争和技术替代抵消；
- 全球产业变化如何映射到 A 股公司；
- 哪些公司具有真实的利润弹性和竞争优势；
- 当前价格已经反映了多少预期；
- 哪些股票在 Bear / Base / Bull 情景下风险收益比更好。

## 核心流程

```text
用户确认行业
→ 数据能力审计
→ 产业链与供需研究
→ 资本周期与利润池
→ 全球竞争格局
→ A股全市场公司母池
→ 一次性请求Choice数据
→ 主题暴露初筛
→ 整家公司质量与盈利兑现验证
→ 分产品盈利模型
→ Bear / Base / Bull估值
→ 核心候选与组合方案
→ 定期维护和证伪
```

## 研究原则

- 先产业、后公司，不从热门股票倒推投资逻辑。
- 严格区分好产业、好生意和当前价格下的好股票。
- 同时研究需求与供给，并纳入资本周期、扩产、价格和 ROIC。
- 主题业务决定增量方向，但估值必须覆盖上市公司全部业务。
- 海外公司主要作为需求、技术、产能和竞争格局锚点，最终映射回 A 股。
- 缺失数据记为 `NA`，不把空值当作零，也不因数据缺失机械排除公司。
- 所有关键数字记录来源、口径、数据日期和估算方法。
- 公司母池形成后，一次性用自然语言向用户请求 Choice 数据，减少重复手工导出。

## 安装

### 直接导入

下载 GitHub Release 中的 `industry-stock-selection-upload-ready.zip`，将 ZIP 直接交给支持 Skill 导入的 Codex 环境。

### 手动安装

将仓库下载或克隆到 Codex 的 Skills 目录，并确保目录结构如下：

```text
skills/
└── industry-stock-selection/
    ├── SKILL.md
    ├── README.md
    ├── agents/
    ├── references/
    ├── scripts/
    └── assets/
```

## 使用示例

```text
使用 $industry-stock-selection 研究机器人产业链。

行业方向已经由我确认。最终投资范围是A股，预测期以未来2—3年盈利为核心、
3—5年判断产业空间。先执行数据审计，确认后再继续产业地图、公司母池、
盈利预测、估值和最终候选。
```

也可以复制并修改 [`assets/project-template/START_PROMPT.md`](assets/project-template/START_PROMPT.md) 中的启动提示词。

## 项目结构

- [`SKILL.md`](SKILL.md)：Agent 的核心工作规则与阶段门槛。
- [`references/`](references/)：产业地图、数据标准、筛选建模、交付和维护方法。
- [`assets/project-template/`](assets/project-template/)：研究项目的标准目录和表格模板。
- [`scripts/init_project.py`](scripts/init_project.py)：初始化新的行业研究项目。
- [`scripts/validate_project.py`](scripts/validate_project.py)：检查项目文件是否完整。

## 数据说明

公开资料优先使用公司公告、财报、监管披露、投资者交流、上下游验证和行业协会数据。Choice 等终端数据由用户手工导出；Skill 会在完整公司母池形成后，一次性给出通俗、可操作的数据需求清单。

本项目是一套研究工作流，不承诺收益，也不能替代独立判断。估值、盈利预测和组合结论都应结合最新数据持续验证。
