# 筛选、盈利模型与估值

## 第一轮：主题机会排序

建议维度：产业与本地捕获20、主题证据与利润弹性15、竞争地位10、未来三年增长20、预期修订15、增长调整后估值15、数据置信度5。

允许少量显式产业判断调整，但必须保存机械分、调整值、理由和最终分。缺失数据给中性或低置信度处理，不能直接给零并淘汰。

## 第二轮：整家公司质量

建议维度：存量业务质量20、盈利质量15、竞争优势15、资本周期15、主题增量质量20、估值与预期15。

这一轮专门纠正第一轮偏向“纯度”的问题。平台型公司即使主题收入占比暂时不高，只要增量足以改变合并利润或竞争地位，也必须进入研究范围。

## 盈利兑现桥

对当年已有中报或季报时，至少计算：剩余期间所需收入和利润、非经常利润占比、现金转化率、现金Capex代理、扩产现金缺口代理、近似有息负债和近似净负债。

半年数据存在季节性，不能机械年化。不同指标可能来自不同预测机构样本，不能因为都在Choice表内就互相推导。

## 产品模型

优先使用 `收入 = Volume x ASP`。无法取得销量时使用 `收入 = 有效产能 x 利用率 x 单位价值量`，或 `历史收入 x 需求增速 x 份额变化 x 产品结构变化`。

利润桥至少包含产品结构、毛利率、费用率、折旧、汇率、股份支付、税率和少数股东。多业务公司保留全部非主题业务。

## 不同商业模式

- 重资产制造：有效产能、良率、利用率、折旧、营运资金、扩产回报。
- 轻资产芯片/IP：外部制造供给、研发、生态、客户复购、股份支付。
- 设备：订单、发货、验收、合同负债、客户Capex、售后与重复销售。
- 材料/耗材：单耗、份额、认证、复购、原料价格和价格传导。
- 平台/整机：主题收入占比、单位利润、客户议价、库存、应收和现金转换。
- 软件/应用：付费用户、ARPU、留存、推理成本、毛利增量与销售效率。

## Bear/Base/Bull

三种情景必须由业务变量分叉，而不是直接给净利润乘任意折扣。每种情景记录销量/产能、ASP、份额、毛利率、费用率、Capex、营运资金、估值倍数、目标日期和证伪条件。

估值对象始终是整家公司。目标价只是情景结果，不是精确承诺。

## 最终排序

综合判断产业成长、主题利润弹性、护城河、盈利确定性、技术寿命、管理层与资本配置、财务质量、当前估值和赔率。不要因高PE或高波动机械扣分；真正惩罚增长无法兑现、竞争恶化、路线替代、利润率不可持续、过度扩产和价格远超合理盈利路径。
