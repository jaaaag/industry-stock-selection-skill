# Choice手工取数请求

本文件在公司母池形成后填写，并将证券代码清单一并交给用户。必须一次性覆盖全部母池公司和可预见字段，避免后续分批补取。

## 给用户的请求

请在Choice中一次性导出代码清单内全部公司的数据。空值原样保留，不需要删除公司或补零。建议一家公司一行、一个指标一列，预测年度分别展开。

需要的数据包括：

1. 基础信息：证券代码、公司名称、财年截止日、币种、单位和数据截至日。
2. 最近完整交易日：收盘价、总股本、总市值、自由流通市值、PE-TTM和企业价值EV（如有）。
3. 未来三个财年一致预期：营业收入、归母净利润、EPS、预测PE、营业利润或EBIT、EBITDA、毛利率、经营活动现金流或每股经营现金流，以及各指标覆盖分析师数量。
4. 一致预期变化：营业收入、归母净利润和EPS相较1个月前、3个月前的预测值或修订幅度；如可以，增加当前最大值、最小值和中位数。
5. 历史财务：最近三年及最新一期的营业收入、毛利率、营业利润、归母净利润、扣非归母净利润、经营活动现金流净额、现金Capex、研发费用、存货、应收账款及票据、合同负债、货币资金、总资产、总负债、有息负债或有息负债率、总股本。
6. 如Choice提供FCFF和FCFE，可以同时导出并保留负值；请同时保留原始经营现金流和现金Capex。
7. 请保留Choice原字段名称或字段说明，并注明一致预期采用均值、中位数还是其他口径。
